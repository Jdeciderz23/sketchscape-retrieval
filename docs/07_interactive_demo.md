# SketchScape 答辩演示

在 Finder 中双击 project 目录下的 `启动检索演示.command`。终端显示“SketchScape 就绪”后会打开浏览器。答辩期间保持终端开启，结束时按 Control-C；服务运行期间再次双击可以重新打开页面。[打开本机演示](http://127.0.0.1:8765/)

## 草图从哪里来

回放使用 FS-COCO 发布的手绘笔迹和配对照片。每个采样点都有坐标、笔的状态和时间戳。画到 25% 指从首点到末点经过了四分之一的绘制用时。页面按记录的时间和笔顺播放，暂停时显示用于实际检索的栅格草图。[数据来源与校验](02_dataset_and_model_validation.md) · [FS-COCO 官方数据页](https://fscoco.github.io/)

12 个展示案例由我们在完成评测后从 Normal 测试集挑选。选择条件为 25% 时目标从首位以外升至第 1，50% 和 75% 时优化检索均在前 3，完整草图的默认结果排第 1。再按照片内容选择动物、运动、交通和建筑等题材。每次查询仍与全部 3,000 张测试照片比较。全测试集在 25% 用时的首位命中率为 11.90% → 16.17%，75% 用时为 51.80% → 50.47%。答辩报告使用全量指标说明整体效果。[完整实验结果](06_prefix_adapter_results.md)

## 三分钟演示顺序

1. 打开后展示斑马草图的 25% 时间点。请观众先看画布，再看目标照片。原始检索把目标排在第 36，优化后排到第 1。两列各展示前五张，命中的目标照片带绿色标记，点击可查看完整照片。
2. 点击“切换案例”，从照片墙选择不同题材。例如“弯道上的列车”在 25% 时从第 43 升到第 1，“跃过障碍的马”从第 7 升到第 1。点“重播”观看真实笔顺，用进度条或百分比按钮暂停比较。右上角播放期间的进度对应最近一次返回的检索结果。
3. 切到“现场手绘”，第一次进入会随机给出一张参考照片。点“选参考图”可翻看整个测试图库，按常见中文题材（如火车、风筝、长颈鹿）、英文原描述中的关键词或照片编号搜索。点“随机一张”在整个图库中抽取另一张，即使刚才用了搜索也一样。点击画布上方的参考照片可以放大。
4. 照着照片画，抬笔后查看两列的前五张和目标名次。参考图只决定要追踪哪张照片的排名。换图会保留笔画并重算目标排名，想换一张重新画可点“清空”。移除参考图可自由手绘。切回回放再返回，画布和参考图都会保留。

“画完了”和回放的 100% 均进入完成模式。优化检索默认使用原始完整特征，此时两列相同。勾选“完稿后继续优化”可观察在完整草图上仍应用适配器的效果。再次落笔或点“继续绘制”可返回部分草图检索。

## 运行与验收

在 project 目录也可从终端启动。页面、照片、缓存及模型都在本机，默认设备为可用的 MPS 或 CPU。换电脑时需带上项目运行资源并配置 Python 环境。需要指定 CPU 或端口时可用 `./启动检索演示.command --device cpu --port 8766`。

```bash
./启动检索演示.command
```

两列使用相同的查询与测试图库，通过官方平方欧氏距离排序。25%、50%、75%、100% 回放复用本次实验提取的前缀或完整特征，其他时刻和手绘输入直接调用编码器。手绘参考照片的像素不会传给查询编码器。

服务运行时可在 project 目录执行验收，自定义端口时附加 `--port`。

```bash
.venv/bin/python demo/check_demo.py
```

验收逐点核对 12 组回放坐标、抬笔和时间，逐像素核对 48 个固定进度的草图，并将两列的目标名次及首位照片与已有全量评测记录比对。另查验图库成员、案例以外的参考图、自由画与完稿模式。[接口验收日志](../outputs/demo/api_check.log) · [浏览器验收日志](../outputs/demo/browser_check.log) · [投影视图](../outputs/demo/projector.png)
